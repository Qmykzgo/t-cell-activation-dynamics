# figures/

All figures are generated by `targets::tar_make()` via `scripts/05_visualization.R`.
Each figure is saved as both **PNG** (300 DPI, for README/web) and **PDF** (vector, for publication).

| File | Description | Script function |
|---|---|---|
| `fig01_pca.png/.pdf` | PCA of VST counts — PC1 vs PC2 and PC1 vs PC3. Coloured by condition, shaped by time. 90% confidence ellipses. | `plot_pca()` |
| `fig02_sample_distance_heatmap.png/.pdf` | Sample-to-sample Euclidean distance matrix. Annotation bars: time, condition, donor. | `plot_sample_distance_heatmap()` |
| `fig03_volcano_panels.png/.pdf` | Multi-panel volcano at 6h, 24h, 72h. LFC = ashr-shrunk; top genes labelled. | `plot_volcano_panels()` |
| `fig04_ma_interaction.png/.pdf` | MA plot for the condition×time interaction LRT. Loess trend line. | `plot_ma_interaction()` |
| `fig05_gene_trajectories.png/.pdf` | Mean ± SEM expression trajectories per cluster (z-score). Faint lines = individual genes. | `plot_gene_trajectories()` |
| `fig06_cluster_heatmap.png/.pdf` | Heatmap of top-membership genes. Rows = genes ordered by cluster; columns = activated samples ordered by time. | `plot_cluster_heatmap()` |
| `fig07_pathway_dotplots.png/.pdf` | GO:BP enrichment dot plots faceted by cluster. Size = gene ratio; colour = –log10(adj. p). | `plot_pathway_dotplots()` |
| `fig08_temporal_pathway_heatmap.png/.pdf` | Temporal pathway enrichment. Rows = GO terms; columns = time points. –log10(BH-adj. p). | `plot_temporal_pathway_heatmap()` |
| `fig09_ari_concordance.png/.pdf` | ARI matrix comparing Mfuzz, NMF, and spline k-means clustering solutions. | `plot_cluster_concordance()` |

> Figures are **git-ignored** (regenerated by the pipeline).
> See `.gitignore` — only this README is tracked.
